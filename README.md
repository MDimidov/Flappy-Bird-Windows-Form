# Flappy Bird Windows Form

Welcome to **Flappy Bird Windows Form**, a simple recreation of the classic Flappy Bird game built using C# and Windows Forms.

---

## 🎮 Features
- **Classic Gameplay**: Navigate the bird through pipes without crashing.
- **Customizable Mechanics**: Adjust the game's speed, gravity, and difficulty.
- **Simple Graphics**: Clean and straightforward visuals suitable for beginners.
- **Fun Learning Experience**: Ideal for developers exploring game development with Windows Forms.

---

## 📚 About the Project
This project was created as a learning experience following this tutorial: [C# Tutorial - Make a flappy bird game in windows form](https://www.youtube.com/watch?v=yUCCv-sFUDQ). The purpose was to explore C# programming in the context of game development and Windows Forms.

---

Build and run the project.

## 🔧 Technologies Used
- **C#**: For the game's logic and mechanics.
- **Windows Forms**: For the graphical user interface and event handling.

## 🌟 Goals of the Project
- Learn and practice event-driven programming.
- Understand collision detection and simple game mechanics.
- Develop a fun and interactive application with Windows Forms.
